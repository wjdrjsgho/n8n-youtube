## **AI의 난제 해결 능력**

- 수학 및 이론 컴퓨터 과학 분야의 10년간 미해결 난제 10가지 AI가 해결했다는 소식임.

- 인류가 해결하지 못했던 문제들을 AI가 해내는 세상으로, 특이점이 얼마 남지 않았다는 생각임.

- 해결된 문제의 구체적인 예시로는 고차원 구형 패킹 밀도에 대한 새로운 상한값, 이진 코드 및 구형 코드 관련 문제 등이 있으며, 모두 유명한 미해결 문제들임.

- 단순한 환각(hallucination)이 아닌, 각 논증을 린 인증서(검증 가능한 공식화 방법론)로 공식화하여 검증 가능성을 확보함.

- 이러한 증명은 강사의 차세대 주요 모델인 아스트라의 내부 버전을 통해 얻어졌음.

- 아스트라와 같은 새로운 모델이 출시되면 기존에 해결하지 못했던 난제들을 해결할 수 있다는 놀라운 사실을 보여줌.

- 이러한 AI의 능력은 박사급 전문가가 오랫동안 연구해야 겨우 이해할 수 있는 영역을 AI가 그 이상으로 달성하는 것이며, 해당 진로를 선택하는 인간의 수가 줄어들 가능성도 있다고 생각함.

## **GPT 5.6 업데이트: 가격 및 성능 확장**

- 가격 대비 성능의 한계를 확장했음.

- <strong>가격 인하:</strong>

- 루나(가장 가벼운 모델) 가격을 7월 30일부터 80% 인하함.

- 루나의 현재 가격은 입력 1달러, 출력 1.2달러임.

- 테라(중간 모델) 가격도 20% 인하함.

- 테라의 현재 가격은 입력 2달러, 출력 12달러임.

- 이로 인해 가성비가 훨씬 좋아졌음.

- <strong>속도 향상:</strong>

- 5.6 솔(Sol) 모델은 기존 수준을 유지하면서 스탠더드 모델 대비 최대 2.5배 빠른 속도를 2배 가격에 제공함.

- 속도 관련 업데이트가 있었음.

- <strong>성능 향상 및 하네스(Harness)의 중요성:</strong>

- 두 가지 설정을 활성화하여 아크 AGI3 점수를 3배로 높였음.

- 기존에는 아웃풋 토큰을 늘릴수록 점수가 10% 남짓 상승했지만, 리즈닝을 보유하면서 압축하는 방법론을 적용한 하네스를 사용했더니 같은 모델임에도 점수가 약 40%가량(13.3%에서 38.3%까지)으로 크게 향상됨.

- 이는 모델의 성능을 측정하는 벤치마크 점수가 API 설정, 하네스 설계, 프롬프트 방식 등 눈에 띄지 않는 여러 요소들이 함께 측정되는 것임을 시사함.

- 따라서 하네스 설계가 매우 중요함을 알 수 있음.

## **Deepseek V4 Flash 정식 출시**

- 이전에는 프리뷰였으나, 이번에 정식 버전이 출시되었음.

- API가 공개되었고 오픈 웨이트도 나왔으며, MIT 라이선스(무료 다운로드 및 사용 가능)로 출시됨.

- <strong>벤치마크 성능:</strong>

- 이전 프로 모델을 훨씬 뛰어넘는 전반적으로 우수한 성능을 보임.

- Fable 출시 전 최강 모델이었던 Opus 4.8과 거의 견줄 정도의 성능임.

- 객관적인 Artificial Analysis 점수 기준으로 구글의 최첨단 플래시 모델과 동급의 성능을 보여줌.

- <strong>API 가격:</strong>

- 코어 가성비로 구글이 밀고 나왔던 Gemini 3.5 Flash Lite보다 성능은 좋으면서도 훨씬 저렴함.

- Fable 5보다 105배 저렴하다는 언급이 있음.

- 이제 웬만한 가성비 작업은 Deepseek V4로 해결 가능할 것으로 보임.

- <strong>오픈 웨이트 및 하드웨어 요구사항:</strong>

- 오픈 웨이트로 출시되어 언슬로스(Unsloth)와 같은 곳에서 양자화된 모델들을 출시할 예정임.

- 양자화된 모델의 하드웨어 요구사항은 다음과 같음:

- 4비트 압축 (손실 거의 없음): 162GB 통합 메모리.

- 3비트 양자화: 128GB 통합 메모리에서 실행 가능.

- 2비트 양자화: 좀 더 넉넉하게 실행 가능.

- GGX Spark 등 고성능 하드웨어를 가진 사용자들은 돌려 볼 만 할 것임.

## **Claude Code 팀의 프롬프트 엔지니어링 조언**

- Y Combinator 강연에서 클로드 코드(Claude Code) 팀의 헤드인 보리스 체르니(Boris Cherny)가 조언을 제공함.

- <strong>프롬프트 감축:</strong>

- 클로드 코드 프롬프트의 80%를 삭감했다고 밝힘.

- 모델의 지능이 향상됨에 따라 이전 모델에서 부족했던 점을 보완하기 위해 시스템 프롬프트 구문의 80% 이상을 삭제함.

- 기존 프롬프트나 코드를 그대로 사용하는 경우가 많지만, 줄이는 것이 더 낫다는 조언임.

- 절제 과정이 필요하며, 기존 프롬프트나 코드를 삭제하고 모델의 실제 반응을 관찰하여 필요한 부분만 다시 채워 넣는 방식을 채택하고 있음.

- 기존 하네스 시스템을 사용하는 경우, 삭제하고 생 모델에서 조금씩 추가하는 형태로 재구성하면 더 좋아질 확률이 있음.

- <strong>새로운 컨텍스트 엔지니어링 규칙:</strong>

- 클로드 코드 팀원이 'New Rules of Context Engineering'이라는 글을 게시함.

- 핵심 패러다임이 변했으며, 이전에는 지침을 극도로 세심하게 상세하게 작성하는 방식이었으나, 현재는 자율적 판단에 위임하는 것이 더 낫다고 설명함.

- 엔트로픽(Anthropic) 모델을 활용한다면 이를 적용하는 것이 좋다는 제안임.

- 도구 사용법을 친절하게 설명해 주는 방식 대신, 파라미터와 구조만 명확히 설계하면 모델이 예시나 사용법을 알려주지 않아도 스스로 이해한다는 점이 놀라움.

- 결론적으로 기존 프롬프트나 코드를 80% 삭감하고 시도해 보면 더 나은 작업 결과를 얻을 수도 있다는 요약임.

## **LLM 벤치마크의 발전**

- 안드레 카파시(Andre Karpathy)의 최근 트윗 내용임.

- 이전에는 LM 테스트를 위해 '자전거를 탄 펠리컨 SVG'를 만드는 것이 유행이었으나, 이제는 해당 방식의 테스트 영역을 벗어나기 시작했다는 주장임.

- 현재는 '자전거 탄 펠리컨' 생성이 매우 잘 되기 때문임.

- 새로운 테스트 아이디어로 '반지의 제왕' 첫 번째 단락을 주고 자바스크립트 렌더러로 애니메이션을 만들게 하는 것을 제시함.

- 이는 2D로는 평가하기 어려워졌으며, 폴리곤 3D로 '반지의 제왕' 한 장면을 만드는 정도의 수준으로 비교해야 한다는 의미임.

- 점점 벤치마크 방식도 발전하고 있다는 것을 보여줌.

## **영상 생성 AI 업데이트**

- <strong>Sidence 2.5 글로벌 런칭:</strong>

- 영상 생성 AI의 강자인 Sidence 2.5 모델이 글로벌 런칭되어 누구나 사용 가능함.

- 가격은 비싸지만 성능이 크게 향상됨.

- 주요 기능:

- 단일 생성으로 네이티브 30초 비디오 생성 가능.

- 인터랙티브 편집으로 최대 3분 길이의 영화급 프로덕션 파이프라인 제공.

- Maya, Blender와 같은 3D 도구용 플러그인이 출시되어 3D만 만들어도 영상으로 변환 가능함.

- 시연 예시:

- 30초 길이의 Logitech 광고 영상: 고품질의 긴 영상 한 번에 생성 가능.

- 2.0 버전과 2.5 버전 비교: 2.5 버전이 확실히 더 현실적인 느낌과 빛 표현이 좋음.

- Frozen Time 효과 및 되돌리기 기능 시연.

- K-POP 뮤직비디오 생성: 다양한 장면 전환과 아이돌 뮤비 같은 결과물을 프롬프팅과 장면 설정만으로 구현 가능.

- 사용 비용: 한 번 생성할 때 약 만 원 정도 소요되므로 신중하게 사용해야 함. 현재까지 퀄리티 중 가장 좋다고 평가됨.

- <strong>Minimax H3 (오픈 멀티모달 모델):</strong>

- 영상 생성이 가능한 멀티모달 오픈 모델임.

- 성능:

- Artificial Analysis 리더보드 기준으로 Sidence 2.0을 넘어섬.

- 텍스트-비디오, 이미지-비디오 분야에서 2위이며, 비디오 에디팅 리더보드에서는 옴니 플래시와 Sidence를 넘어서 1위를 차지함 (오픈 웨이트 모델 중).

- 오픈 웨이트 출시: 아직 모델 웨이트는 공개되지 않았으나 (언급 시점 기준 약 6시간 후 공개 예정), RTX 3060 한 장으로도 돌릴 수 있을 것이라는 이야기가 있음.

- 컴피어(Comfy)의 창립자가 8비트 가중치로 3060 그래픽카드를 이용해 3240x1240 해상도에서 124프레임 비디오를 10분 이내에 성공적으로 생성했다고 함.

- 자세한 스펙은 미정이나, 오픈 소스 영상 기술의 진보를 기대할 수 있는 모델임.

- 시연 예시: K-드라마 스타일의 영상 생성 (목소리 대사 등이 잘 나옴).

- <strong>Imagine Video 1.5 버전 개선:</strong>

- 이전 버전 대비 더 좋아졌음.

- 레퍼런스를 넣고 영상을 만들 수 있으며, 나쁘지 않은 결과물을 보여줌.

- 조코딩 채널 소개 영상을 이전과 같은 프롬프트로 생성한 결과, 춤 동작이 더 자연스러워지고 15초까지 생성이 가능해짐.

- 1080p 해상도 지원.

## **음성 모델 업데이트**

- <strong>Voice ThinkFast 2.0 공개:</strong>

- 추론 기능이 들어간 음성 모델임.

- 음성 추론, 대화 능력 및 도구 사용이 가능한 모델임.

- 성능:

- GPT Real-Time 2.1 혹은 Gemini 3.1 Flash와 비교했을 때 점수 차이가 크며, 나머지 모델들보다 훨씬 뛰어남.

- 음성 추론 영역에서 97.2점을 기록.

- 대화 역학에서는 약간 낮지만 큰 차이는 없음.

- 속도가 굉장히 빠름.

- Groq Voice를 이용한 상담원이나 실시간 통화 서비스 제작에 적합해 보임.

- ElevenLabs Scribe V2 대비 1.5배에서 2배가량 향상된 성능을 보임.

- 음성 모델을 고려하는 사용자들에게 추천할 만함.

- <strong>Crisper Whisper 2.0 (오픈 웨이트 ASR 모델):</strong>

- 소리가 들어가면 텍스트로 나오는 ASR(Automatic Speech Recognition) 모델로, 매우 빠르고 정확함.

- 성능 비교:

- ElevenLabs Scribe V2 (자막 제작에 많이 사용)가 79.2점인 반면, Crisper Whisper 2.0은 87.8점으로 매우 높음.

- 오픈 웨이트 모델 중 현존 최고 성능을 보이며, MAI Transcribe도 뛰어넘음.

- 특징: '어', '아'와 같은 감정 표현이나 웃음 소리 등을 따로 걸러주는 기능이 있음.

- 한글 전사도 잘 되며, 텍스트로 전사할 때 매우 유용할 것으로 보임.
