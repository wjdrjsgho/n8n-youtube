## **AI를 활용한 PPT 제작의 새로운 패러다임: Claude Design 소개**

- 직장인 및 학생에게 PPT 제작은 시간 소모가 크고 디자인 감각이 부족한 사람에게는 깔끔하고 알찬 PPT 제작이 매우 어려운 일임.

- 기존 템플릿은 마음에 드는 것이 없고, AI로 만든 결과물은 AI 티가 나는 경우가 많아 스트레스받는 작업 중 하나임.

- 이러한 PPT 제작의 어려움을 해결할 끝판왕 AI로 '클로드 디자인(Claude Design)'을 소개함.

- 클로드 디자인은 프롬프트 입력만으로 내용 기획부터 구성, 디자인까지 자동으로 수행하는 플랫폼임.

- 클로드 디자인이 출시된 지 몇 달 되었고 이미 유명하지만, 대부분의 사용자가 클로드 디자인을 잘못 사용하고 있다고 판단됨.

- 대부분 템플릿 선택 후 간단한 프롬프트로 PPT를 만들지만, 이 경우 흔하고 일반적인 결과물만 생성됨.

- 완성도가 아주 낮지는 않지만, 그대로 사용하기에는 부족하고 애매한 퀄리티의 결과물이 나옴.

- 이 영상의 목표는 왕초보도 그럴듯한 PPT를 만드는 것을 넘어, 언제든지 필요할 때마다 고품질 PPT를 생성할 수 있는 '나만의 PPT 공장'을 구축하는 방법을 소개하는 것임.

## **Claude Design 사용 시작하기**

- Claude에 접속하여 왼쪽 탭의 '디자인'을 클릭하면 새로운 창이 열리며 클로드 디자인 화면이 나타남.

- 현재 정식 출시 전의 베타 버전이므로 메뉴가 영어로 나오지만, 실제 프롬프트 입력이나 결과물은 한국어로 잘 만들어주므로 걱정할 필요 없음.

- 클로드 디자인의 핵심 기능은 '나만의 템플릿'을 만들 수 있다는 점임.

- 자주 하는 업무, 선호하는 디자인, 회사 양식 등을 기반으로 템플릿을 한 번 만들어 놓으면 이후 계속해서 다른 PPT를 만들 수 있음.

- 오늘의 목표는 회의, 미팅, 발표 등에 공통적으로 사용할 PPT 템플릿을 만드는 것임.

## **나만의 디자인 규칙 '디자인 MD' 파일 생성**

- PPT 템플릿을 만들기 위해서는 '디자인 MD'라는 파일이 필요함.

- 디자인 MD는 원하는 디자인의 느낌, 컬러, 폰트, 간격, 스타일 등 디자인 규칙이 담긴 일종의 파일임.

- 매번 PPT 제작 시 디자인 요소를 다시 설명하고 프롬프트로 입력하는 번거로움을 줄이기 위해 파일로 정리하는 개념임.

- 디자인 MD 파일을 만드는 방법은 여러 가지가 있음.

- <strong>다른 사람이 만들어 놓은 레퍼런스 파일 활용:</strong>

- '디자인 MD'라는 웹사이트에 접속함.

- 이 사이트에서는 BMW, 닌텐도, 에어비앤비, 애플 등 주요 브랜드의 키 컬러, 폰트 등 디자인 요소가 추출되어 MD 파일로 정리되어 있음.

- 원하는 브랜드를 클릭하여 사용 중인 컬러, 폰트 스타일을 확인하고, 마음에 들면 다운로드 버튼을 눌러 파일을 받음.

- <strong>주의사항:</strong> 다른 브랜드 색깔이 강하거나 지적재산권 문제가 우려될 경우, 해당 파일을 클로드에 첨부하고 다음과 같이 요청함.

- "이 디자인 MD 파일에서 지적 재산권이나 라이선스 등 문제가 될 만한 요소들을 제거하고 다른 요소로 대체해 줘. 그 외적인 스타일은 동일하게 유지해 줘."

- <strong>기존에 사용하던 회사 양식 활용:</strong>

- 기존에 사용하던 레퍼런스 파일 (예: 지난 발표 PPT)을 첨부함.

- 클로드에 "이 PPT 파일을 보고 키 컬러, 폰트, 스타일 등 디자인 요소들을 추출해서 디자인 MD 파일로 만들어 줘."라고 요청함.

- <strong>독창적인 디자인 규칙 처음부터 만들기:</strong>

- 아무 디자인 MD 파일을 첨부함.

- 클로드에 "나는 이런 식으로 나만의 디자인 규칙을 담은 디자인 MD 파일을 만들고 싶어. 지금부터 필요한 요소들을 나에게 인터뷰하듯이 질문해서 내 답변을 바탕으로 파일을 만들어 줘."라고 입력함.

## **클로드 디자인 시스템 구축하기**

- 디자인 MD 파일을 만들었다면, 이제 이를 바탕으로 '디자인 시스템'을 구축할 차례임.

- 디자인 MD 파일은 클로드 외 다른 AI에도 공통으로 사용할 수 있는 범용 디자인 요소 집합임.

- 반면, 디자인 시스템은 오직 클로드 디자인에 최적화된 형태임.

- 디자인 MD 파일을 디자인 시스템으로 변환해두면 색깔, 글꼴, 로고 같은 디자인 요소들을 동일하게 유지하면서 슬라이드, 카드 뉴스, 웹사이트, 모션 그래픽 등 일관된 스타일의 결과물을 얻을 수 있음.

- 디자인 시스템 구축 방법은 다음과 같음.

- 클로드 디자인에 접속하여 프롬프트 창 우측에서 모델을 선택함.

- 디자인 시스템은 앞으로 계속 사용할 것이므로 처음 만들 때 확실히 잘 만드는 것이 중요하여, 상위 모델인 '오포스(Opus)'를 선택하고 추론 강도도 '맥스(Max)'로 설정함.

- 왼쪽의 '디자인 시스템' 탭을 클릭하고 '셋업 유월 디자인 시스템(Setup Your Design System)'을 누름.

- 두 가지 옵션 중 첫 번째인 '크리에이트 히어(Create Here)'를 클릭하면 창이 나타남.

- 맨 위에 이름을 입력하고, 맨 아래 '애스 로스 앤(As Source And)' 항목에 아까 만든 디자인 MD 파일을 첨부함.

- 우측 상단의 '컨티뉴(Continue)'를 누르고 약 5분에서 10분 정도 기다림.

- 클로드가 MD 파일을 읽어 키 컬러, 폰트, 스타일 등 디자인 요소들을 분석한 후 디자인 샘플을 만들어줌.

- 디자인 시스템이 어떻게 설계되었는지 텍스트로 정리된 내용과 함께 실제 결과물이 어떻게 나오는지 샘플도 보여줌.

- 각 요소마다 어떤 컬러, 폰트가 사용되었는지, 구성 요소는 무엇인지 등 확인할 수 있음.

- 디자인 MD 파일에 이미 완성도 높은 레퍼런스의 요소와 규칙이 담겨 있어, 처음 만들어진 결과물도 퀄리티가 높음을 확인할 수 있음.

- 샘플을 직접 확인하면서 수정하고 싶은 부분은 프롬프트로 요청하여 수정할 수 있음.

- 예: 워드마크에서 피드백 버튼을 누르고 "이 워드마크 폰트를 깔끔한 고딕체로 바꿔 줘"라고 요청하면 수정해줌.

- 기존에 사용하던 회사 로고 같은 것들도 추가할 수 있음.

- 예: 회사 로고와 자주 사용하는 아이콘들을 첨부한 다음 "내 회사 로고랑 자주 사용하는 아이콘들 첨부했으니까 소스에 추가해 줘"라고 입력함.

- 클로드가 아이콘들을 소스에 추가해주며, 심지어 검은 글씨 버전 로고를 첨부하지 않았는데도 알아서 잘 만들어주는 똑똑함을 보임.

## **PPT 템플릿 생성 및 실제 PPT 제작 과정**

- 나만의 디자인 시스템이 완성되면, 이 시스템을 사용하여 PPT뿐만 아니라 카드 뉴스, 랜딩 페이지, 모션 그래픽 등 일관된 스타일의 결과물을 만들 수 있음.

- <strong>PPT 템플릿 생성:</strong>

- 프롬프트로 "좋아. 이제 이걸 가지고 AI 교육용으로 사용할 PPT 템플릿을 만들어 줘. 레이아웃이나 PPT 장수는 네가 알아서 정해."라고 입력함.

- 클로드가 총 14장의 슬라이드를 생성해줌.

- 생성된 슬라이드를 확인하면, 디자인 시스템에 있던 컬러를 사용하고 요즘 트렌드에 맞게 심플하고 깔끔한 레이아웃으로 구성되었음을 알 수 있음.

- 자연스럽게 요소들이 들어가고 이전에 첨부한 아이콘들도 적절한 곳에 활용되었음.

- <strong>실제 PPT 제작:</strong>

- 클로드 디자인에서 디자인 시스템과 방금 만든 템플릿을 선택함.

- AI 강의 스크립트를 첨부함.

- 프롬프트로 "첨부한 대본을 바탕으로 강의에 사용할 PPT 만들어 줘. 필요한 부분이 있으면 나한테 요청해."라고 입력함.

- 클로드가 PPT 생성을 위해 필요한 부분들을 질문함. (예: 강의 시간, 화면 캡처 직접 넣을 건지 등)

- 질문들은 타이핑으로 일일이 작성할 필요 없이 선지 형태로 제공되어 선택할 수 있어 편리함.

- 질문에 답변을 선택하여 제시한 후 '컨티뉴' 버튼을 누르면 슬라이드를 생성해줌.

- 결과물을 확인하면 방금 만든 템플릿의 양식에 맞게 내용에 따라 적재적소에 레이아웃을 구성했으며, 디자인도 깔끔함.

- 사람이 만든 것이라고 해도 과언이 아닐 만큼 자연스럽고 퀄리티가 높다고 보임.

- 첨부한 AI 로고들도 잘 들어가 있고, 슬라이드마다 들어간 카드에는 강조 표시도 되어 있음.

## **결과물 편집 및 수정 기능의 편리성**

- 클로드 디자인은 결과물을 편집하고 수정하는 기능도 매우 용이함.

- 프롬프트 입력 외에 파워포인트처럼 직접 작업을 하듯이 편집할 수 있음.

- 상단의 '에(Edit)' 버튼을 누르면 각각의 요소를 클릭할 수 있음.

- 텍스트를 선택하여 문구를 수정하거나 글씨 크기, 굵기 등 조절 가능함.

- 도형, 선, 화살표 같은 요소들도 수동으로 추가할 수 있음.

- 과거 AI로 PPT를 만들면 하나의 슬라이드 전체를 이미지로 생성하여 수정이 어렵고 슬라이드를 아예 다시 만들어야 하는 불편함이 있었지만, 클로드 디자인은 파워포인트처럼 직접 수정할 수 있어 매우 편리하고 작업 속도가 빠름.

- <strong>커멘트(Comment) 기능:</strong>

- '커멘트' 버튼을 누르면 각각의 요소마다 댓글을 달 수 있음.

- 수정이 필요한 부분마다 댓글을 추가하고 "이렇게 바꿔 줘", "저렇게 바꿔 줘"라고 입력해 둔 다음, 마지막에 일괄적으로 수정을 요청할 수 있음.

- 클로드가 요청 사항들을 한꺼번에 반영하여 수정해줌.

- <strong>트윅스(Tweaks) 기능:</strong>

- 왼쪽 상단에 '트윅스' 기능이 있음.

- 어떤 요소를 추가하거나 수정할지 고민될 때, 비교해서 볼 수 있도록 만들어 주는 기능임.

- 예: "슬라이드 우측 하단에 슬라이드 번호 추가해 줘", "우측 상단에 알림 로고 추가해 줘"라고 각각 요청함.

- 요청에 따라 토글이 생성되며, 토글을 끄면 사라지고 켜면 다시 나타나 껐다 켰다 하면서 뭐가 더 나은지 한눈에 파악할 수 있음.

- 슬라이드 번호는 유지하고 로고는 없는 것이 낫다고 판단될 경우, 로고는 끈 상태에서 우측의 '세이브 as 디폴트(Save as Default)'를 눌러 해당 설정을 기본값으로 저장할 수 있음.

- <strong>기본값 저장 (메모리 기능):</strong>

- 모든 수정을 마친 후, 프롬프트로 "지금까지 내가 수정한 내용과 피드백을 바탕으로 다음부터는 기본 값으로 적용이 되도록 메모리 해 줘."라고 요청함.

- 클로드가 "클로드 MD에 기록했습니다."라고 응답하며, 슬라이드 번호 표시, 로고 사용 안 함, 제목 짧은 단원형, 배지나 라벨 그림자 적용 등 어떤 내용들이 적용되었는지 설명해줌.

- '올 프로젝트 파일(All Project File)'에 들어가면 디자인 시스템에 포함된 모든 요소 지침 파일들이 저장되어 있으며, 맨 밑에 '클로드 MD 파일'이 추가된 것을 확인할 수 있음.

- 이 파일을 열어보면 모든 피드백 사항들이 저장되어 있어, 다음부터 PPT를 만들 때 다시 수정할 필요 없이 자동으로 이 내용들이 적용되어 생성됨.

- 이런 식으로 수정이나 피드백이 생길 때마다 저장해두면 템플릿의 완성도가 점점 더 높아짐.

## **결과물 활용 및 Claude Design의 확장성**

- 완성된 PPT는 상단의 '프레젠트(Present)' 버튼을 눌러 해당 사이트에서 바로 발표를 시작할 수 있음.

- '셰어(Share)' 버튼을 눌러 팀원과 공유하거나 파워포인트, PDF 파일 등 원하는 형식으로 내보낼 수도 있음.

- 클로드 디자인은 PPT 외에도 웹사이트, 카드 뉴스 등 다른 것들도 디자인할 수 있음.

- 디자인 시스템에 이미 나만의 스타일이 모두 들어가 있으므로, 카드 뉴스 템플릿, 랜딩 페이지 템플릿, 보고서 템플릿 등을 한 번만 만들어두면 됨.
